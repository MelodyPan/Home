# 全站溫馨可愛主題說明

> 此文件保留當時的設計／評估紀錄，不作為目前完整操作規則。現行行為請看 [使用指南](../../../docs/bookmarks-guide.md) 與 [開發維護說明](../../../docs/bookmarks-development.md)。

設計紀錄日期：2026-10-24；2026-10-29 校正檔案連結與指令。書籤歡迎區後續已移除，下文保留當時設計背景。

導覽：[文件首頁](README.md) · [成長相簿說明](../../growth/docs/growth-album.md)

## 設計範圍

書籤工作台與成長電子相簿共用奶油白、蜜桃粉及柔和淡紫的主題。首頁採簡潔的歡迎區、圓角卡片與柔和陰影；成長相簿保留拍立得照片、紙膠帶、便條紙與時間軸。

工作用途仍使用淡藍色，生活用途使用奶油白，避免不同用途的書籤失去辨識。原有 Logo 圖片、名稱配色與連結功能保留。

## 樣式檔案與載入順序

| 檔案 | 用途 |
| --- | --- |
| [apps/shared/src/cozy-theme.css](../../shared/src/cozy-theme.css) | 共用色彩、按鈕、表單、對話框，以及各頁面的主題調整 |
| [src/home.css](../src/home.css) | 書籤原始版型、格狀／清單排列及功能樣式 |
| [src/home.html](../src/home.html) | 書籤首頁範本、歡迎區與主題引用 |
| [apps/growth/src/growth.css](../../growth/src/growth.css) | 成長相簿版型、拍立得、照片選擇與時間軸 |
| [apps/growth/growth.html](../../growth/growth.html) | 成長相簿入口與主題引用 |
| [scripts/server.cjs](../scripts/server.cjs) | 以固定路由提供共用主題，不公開任意樣式檔案 |

共用主題在各頁原本樣式之後載入。書籤頁使用 `body[data-page="bookmarks"]`，相簿頁使用 `body[data-page="growth"]` 作為範圍，避免同名類別互相影響。

`bookmarks.html` 由首頁範本建置產生，請不要只修改產物；`growth.html` 則直接維護。

## 共用設計變數

| 變數 | 用途 |
| --- | --- |
| `--cozy-bg` | 奶油色背景 |
| `--cozy-paper` | 卡片、輸入框與紙張表面 |
| `--cozy-ink` | 主要文字 |
| `--cozy-muted` | 次要說明 |
| `--cozy-line` | 柔和分隔線及邊框 |
| `--cozy-pink`、`--cozy-plum` | 蜜桃粉／淡紫系的重點色 |
| `--cozy-peach`、`--cozy-lilac` | 淺色裝飾表面 |
| `--cozy-shadow` | 卡片的柔和陰影 |

裝飾主要使用 CSS，沒有新增圖片下載或外部字型服務。歡迎區的小手帳裝飾使用 `aria-hidden="true"`，不干擾螢幕閱讀器。

## 功能與資料

這次主題只調整頁面呈現，沒有修改書籤、孩子、故事或照片資料。首頁歡迎區放在原本的 `home-overview` 內，因此會跟隨既有首頁／清單切換邏輯隱藏。

相簿的大頭貼、封面、時間軸與預覽入口保留；成功載入／保存提示仍隱藏，錯誤訊息正常顯示。右下角先前移除的備份提示也沒有恢復。

網址連線狀態保留原有語意提示，工作／生活仍有用途區別。按鈕和表單提供可見的鍵盤焦點；觸控裝置加大主要操作目標與輸入文字，減少手機操作困難。

## 響應式與動態效果

共用主題沿用各頁原本的斷點，另在 1150、800、740、560、370 像素附近調整歡迎區、留白、卡片與導覽。小畫面允許工具列換行；最窄畫面隱藏純裝飾，保留實際操作。

卡片滑入效果只作輕微位移與陰影變化。系統啟用減少動態效果時，會停用相關動畫與位移。

## 修改與驗證方式

```powershell
node apps/bookmarks/scripts/build-home.cjs
npm test
```

單獨修改 `cozy-theme.css` 後重新整理即可，不需要重建相簿或重啟服務。修改首頁範本後需重建 `bookmarks.html`；修改服務路由後重新執行 `start-home.cmd`，讓啟動器更新版本。

正常啟動後，共用樣式網址為 `http://127.0.0.1:4179/bookmarks/src/cozy-theme.css`。直接以 `file://` 開啟首頁時，無法使用這個本機 HTTP 樣式路徑，請以啟動檔開啟正式介面。

自動驗證涵蓋既有功能測試、靜態資源回應、DOM 識別碼及樣式區塊結構。這些檢查不等同真實瀏覽器的視覺驗收；目前瀏覽器操作受工具權限限制，尚未完成新版畫面的實際截圖驗證。
