# 書籤工作台操作指南

更新日期：2026-10-24。

## 開啟與停止

1. 在專案資料夾雙擊 `start-bookmarks.cmd`。
2. 瀏覽器開啟 `http://127.0.0.1:4178/bookmarks.html`，載入目前的書籤資料。
3. 使用完畢可回到首頁，按最下方的「停止服務」。關閉瀏覽器分頁不會停止服務。

請透過啟動檔開啟，才能自動讀寫資料；直接雙擊 `bookmarks.html` 無法自動讀寫旁邊的文字檔。

## 首頁與清單

- 首頁顯示常用入口、搜尋、新增與資料檔操作區，左側不預選分類。
- 點左側「所有書籤」、「常用收藏」或分類，切換成可編輯的書籤清單。
- 點左上角 Logo 回到首頁。
- 結果區可切換「格狀／清單」，顯示偏好會保存在目前瀏覽器。

## 搜尋與篩選

- 首頁輸入關鍵字，即可搜尋名稱、網址、原始資料夾與第二層分類名稱。
- 分類清單也可按「關鍵字搜尋」展開搜尋框。
- 有關鍵字時，結果中的「工作系統」優先顯示，其他分類接在後面；各組內維持所選排序。
- 按「更多篩選…」可依工作／生活、原始資料夾及網址狀態組合篩選。
- 勾選「僅顯示重複網址」，或在書籤清單上方勾選「重複網址」，即可找出完整網址相同的書籤，並顯示符合目前條件的筆數與組數。卡片標示「同網址 N 筆」，此數量以全部未刪除書籤計算，其他同網址項目可能在不同分類。
- 重複比對保留網址大小寫、查詢參數及片段，不自行合併或刪除書籤；可與其他篩選一起使用。修改網址或刪除書籤後會重新計算；清除所有篩選即可關閉此條件。
- 原始資料夾位於「中榮」底下的書籤維持工作用途。

## 第一層分類排序

點左側「依用途探索」旁的「分類排序」，使用「上移／下移」調整主分類順序，也可恢復預設順序。「所有書籤」與「常用收藏」固定在頂端。

## 第二層分類與排序

「工作系統」與「程式開發」都支援第二層分類，兩者分開管理。

1. 點選左側主分類，再按「管理第二層分類」。
2. 輸入名稱，按「新增分類」。
3. 修改既有名稱後，按「儲存名稱」。
4. 按「上移／下移」調整子分類順序；最上方不能再上移，最下方不能再下移。
5. 關閉管理視窗，點書籤卡片上的分類編輯按鈕，指定第二層分類並儲存。
6. 點左側子分類，即可篩選其中的書籤。

「未分類」固定在子分類清單最後。刪除子分類只會讓相關書籤回到未分類，不會刪除書籤。順序與分類設定會自動保存，重新開啟後仍會保留。

## 書籤與網址狀態

- 卡片或清單按「編輯」，可修改名稱與網址。只修改名稱會保留既有檢查狀態；修改網址會清除該筆手動狀態與自動檢查結果，標示為「未檢查」，收藏、原始資料夾與分類仍保留。
- 勾選書籤後按「批次分類」，可一次移到指定主分類與第二層分類。確認視窗會顯示選取筆數；若包含「中榮」資料夾項目，只提供工作用途分類。
- 「選取全部篩選結果」包含尚未按「再看更多」展開的項目。改變篩選後，不符合條件的選取會取消；可按「取消選取」清空。
- 首頁按「新增書籤」可輸入名稱、網址及分類。
- 點星號加入或移除常用收藏。
- 刪除書籤後可按「復原刪除」。
- 點分類或網址狀態標籤可手動修改。
- 首頁右上角「?」→「重新檢查網址」，可重新確認目前未刪除的書籤；視窗顯示檢查進度及最後完成時間。
- 手動標記狀態與自動檢查結果分開保留；選擇「恢復自動檢查結果」可套用自動結果。

## 儲存與匯出

首頁與清單上方都顯示存檔狀態。若無法儲存，會持續顯示錯誤，並提供「下載目前資料」；一般錯誤可重試儲存，版本衝突則先下載備份，再重新整理，避免覆蓋其他視窗的資料。

| 項目 | 儲存位置或用途 |
| --- | --- |
| 書籤主要資料 | `assets/bookmarks-data.txt`，UTF-8、JSON 格式 |
| 上次存檔前備份 | `assets/bookmarks-data.txt.bak` |
| 第一層分類順序 | `changes.categoryOrder` |
| 第二層分類與順序 | `changes.workSubcategories`，以陣列順序保存 |
| 書籤所屬子分類 | `changes.workSubcategoryAssignments` |
| 書籤名稱與網址修改 | `changes.entryOverrides`，以書籤 ID 記錄；原始資料保持不變 |
| 格狀／清單偏好 | 瀏覽器 localStorage，不寫入書籤 JSON |
| 匯出 Chrome 書籤 | 下載可供 Chrome 匯入的 HTML，保留用途、分類及第二層資料夾順序 |
| 備份 JSON | 下載完整資料，保留狀態、收藏與異動紀錄 |

為相容舊資料，第二層欄位名稱仍使用 `workSubcategories`。其中 `category: "dev"` 代表程式開發，省略 `category` 時代表工作系統。不要只修改衍生的 `entries`，下次存檔會重新產生。

## 截圖與手機查看限制

本次對話中，Windows 本機圖片路徑與圖片預覽在手機端未能成功顯示。`C:/Users/...` 指向電腦檔案，無法直接從手機開啟；在電腦側開啟預覽，也不代表手機端已收到圖片附件。

目前沒有已確認可用的手機附件傳送方式，不能將本機連結當成已成功傳送截圖。可先在存放專案的電腦查看截圖，或由使用者透過自己的檔案分享方式傳到手機。截圖尚未公開上傳。

`127.0.0.1` 也只代表正在使用的裝置；在手機輸入同一網址不會連到電腦上的書籤服務。現有服務僅供電腦本機使用。

## 成長電子相簿

書籤首頁右上角「♡ 成長相簿」可進入孩子的成長手帳。支援多位孩子、大頭貼、每筆紀錄指定封面，以及依日期顯示標題與封面的時間軸預覽。

操作、資料保存與完整程式說明請見 [成長電子相簿說明](growth-album.md)。相簿資料與書籤分開保存，備份時需一起保留 JSON 與照片目錄。
