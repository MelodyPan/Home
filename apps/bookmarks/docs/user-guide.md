# 書籤操作指南入口

更新日期：2026-10-29。

完整操作文件已集中到 [書籤網站使用指南](../../../docs/bookmarks-guide.md)，避免這裡與根目錄文件重複、造成操作說明不同步。

第一次使用先開啟網站，按「登入 → 連接 Google Drive」。既有書籤會自動載入；沒有資料時，再選擇匯入本網站 JSON 備份或建立空白書籤。

閱讀時先記住三件事：

1. 上方「所有書籤／常用收藏」預設是簡易連結；在所有書籤輸入關鍵字後才顯示詳細卡片。下方用途分類維持詳細卡片。
2. 修改會自動同步到私人 Google Drive 的 MelodyHome 資料夾；關閉前確認同步完成，失敗時先下載未同步資料。
3. 線上版目前不能執行網址檢查；本機檢查後同步 Drive，再從線上重新載入結果。

管理者看 [Google Drive 設定](google-drive-setup.md)，維護程式看 [開發維護說明](../../../docs/bookmarks-development.md)。
