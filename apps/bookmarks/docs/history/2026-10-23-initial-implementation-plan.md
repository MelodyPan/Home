# 個人書籤首頁初版實作計畫

> 當時執行方式：依初版計畫逐項實作，使用核取方塊記錄完成情形。

**目標：** 建立清新明亮、可離線開啟的個人書籤首頁，快速分類、搜尋及收藏 546 筆書籤。

**架構：** 從原始 HTML 解析名稱、網址及資料夾，與本機檢查結果合併；以可重建的產生器將資料、共用篩選函式、CSS 及頁面程式嵌入單一 index.html。無外部依賴或發布。

**技術組成：** Node.js 內建模組；原生 HTML、CSS、JavaScript。

**設計文件：** [初版設計](2026-10-23-initial-design.md)

## 整體限制

- 原始書籤保持原樣，重複網址仍保留各筆資料。
- 繁體中文，使用原生 HTML、CSS、JavaScript，不載入外部字型、圖示或追蹤程式。
- 交付 index.html，雙擊即可在 Chrome 開啟，不需安裝套件、啟動伺服器或登入。
- 每筆一個主要分類；不確定者待整理。狀態預設全部顯示。
- 目前不是 Git 儲存庫，不建立工作樹或提交。

## 檢查重點

- 旅遊資料夾中的泰語教材歸語言學習；工作資料夾中的技術教學歸程式開發。
- 重複網址與同名書籤不可遺失；識別碼依原始內容與重複序號穩定產生。
- 特殊協定不可變成可執行連結；帶 HTML 標記的名稱必須當文字顯示。
- 收藏儲存受拒或損壞時仍可操作，顯示提示。
- 手機窄螢幕、長標題、組合篩選無結果及鍵盤焦點不得影響操作。
