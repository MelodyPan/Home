# 個人書籤首頁設計

日期：2026-10-23

## 已確認的補充需求

使用者於網址檢查完成後要求直接產生 HTML，指定清新明亮風格。採暖白底、薄荷綠與淺藍點綴、圓角卡片與清楚的用途導覽。整合已產生的連線檢查結果，提供狀態篩選及檢查說明；保留全部書籤，預設不排除任何狀態。

## 目的與使用方式

將 Chrome 匯出的 546 個書籤整理成依用途分類的繁體中文首頁，讓使用者快速搜尋及開啟網站。使用者已確認重新分類與以下功能設計。

交付 `index.html`，雙擊即可在 Chrome 開啟，不需安裝套件、啟動伺服器或登入。HTML 內含樣式、程式與書籤資料，頁面搜尋及分類不依賴網路；開啟網站本身仍需依該網站的連線條件。

## 輸入與資料處理

- 輸入為 `bookmarks_2026_10_23.html`，原始檔保持原樣。
- 解析 Netscape 書籤格式，保存每筆名稱、完整原始網址及原始資料夾路徑。
- 每筆書籤有穩定識別碼及一個主要用途分類。重複網址仍保留各筆資料，避免遺失原始項目。
- 依名稱、網域及原始資料夾判斷用途；工作內部網址優先歸工作系統，技術教學歸程式開發。無法確定者歸待整理。
- 不造訪書籤目標網站，不推斷連結是否失效。

## 用途分類

AI 工具、程式開發、工作系統、語言學習、旅遊、美食、投資理財、新聞閱讀、影音娛樂、攝影設計、購物生活，以及待整理。

以用途為主要依據，例如旅遊資料夾中的泰語教材歸語言學習；美食遊記若主要介紹餐廳則歸美食。保留原始資料夾供使用者辨識。

## 畫面與互動

- 桌面左側為分類導覽，顯示各類數量；右側為搜尋列與書籤卡片。小螢幕將分類改為可換行的篩選按鈕。
- 提供全部書籤、常用收藏與各用途分類切換。
- 搜尋即時比對名稱、網址、原始資料夾及分類，不分英文字母大小寫。分類與搜尋同時生效。
- 卡片顯示網站名稱、網域、原始資料夾與收藏星號。文字使用安全 DOM API 呈現，避免把匯入內容當作 HTML 執行。
- 網址以新分頁開啟，設定 `noopener noreferrer`。僅允許一般網頁協定；其他協定保留資料與文字，但不建立可執行連結。
- 收藏以 localStorage 保存於目前瀏覽器。若瀏覽器拒絕儲存，收藏在本次頁面中仍可用，並顯示無法永久保存的提示。
- 無結果時顯示明確提示與清除篩選操作。長標題可換行，按鈕可用鍵盤操作並有可見焦點。

## 實作與範圍

使用原生 HTML、CSS、JavaScript，不載入外部字型、圖示或追蹤程式。使用本機產生工具解析來源並嵌入資料，以便日後重新匯出後重建首頁。

第一版不包含雲端同步、帳號、拖曳修改分類、網站連線檢查或自動讀取 Chrome。原始網址可能含內部系統資訊，輸出僅保存於本機，不發布到外部服務。

## 驗收

1. 來源 546 筆與輸出筆數一致；逐筆比對名稱、網址及原始路徑，沒有遺失。
2. 每筆皆有有效分類，各分類數量總和等於全部書籤數量。
3. 中文、英文、網域與原始資料夾搜尋正確；分類、收藏及搜尋可組合。
4. 收藏可切換，重新開啟後在允許 localStorage 的瀏覽器中保留。
5. 實際檢查桌面與手機寬度，確認導覽、長標題、空結果及鍵盤操作可用。
6. 檢查頁面沒有外部資源依賴、可執行的匯入標記或未處理的程式錯誤。
