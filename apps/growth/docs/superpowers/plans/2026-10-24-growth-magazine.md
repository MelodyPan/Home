# 專屬書封、章節目錄與雜誌排版實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 每位孩子可設定書名、寄語、獨立書封照片，電子書依孕期與年份提供跳頁目錄，完整呈現紀錄的所有照片。

**Architecture:** 保持本機檔案與 schemaVersion 1，孩子增加可選 bookTitle/bookDedication/bookCover；故事增加可選 photoLayout。以純函式建立書封、目錄、故事與延伸照片頁描述，沿用既有 3D 翻頁引擎。閱讀跨頁位置與原故事索引分開，避免封面或延伸頁改錯故事。

**Tech Stack:** 原生 JavaScript、CSS Grid、既有照片 API、Node.js 測試。

設計選擇：每本依紀錄日期自動分為孕期篇與年份章節，不新增手動分類維護負擔。雜誌每半頁最多三張、格狀四張、大圖一張，照片按封面優先呈現但不變更保存順序。第一個跨頁保留完整故事，後續以照片延伸；原故事的長文字仍可捲動。年份／搜尋同樣影響電子書內容與目錄。

驗證：94 項測試通過；HTTP 靜態檔案與磁碟一致，DOM ID 無重複或遺漏，正式 JSON 與備份 SHA-256 均未改動。完成唯讀審查，已依回饋讓手機長故事整頁捲動、章節按鈕可換行。實際瀏覽器的外觀、觸控與裁切尚未驗證。
