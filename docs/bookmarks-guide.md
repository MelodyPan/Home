# 書籤網站使用指南

更新日期：2026-10-29。這是給第一次使用者的操作說明，依目前本機程式核對。

這個網站用來整理網站連結。書籤保存在你自己的 Google Drive，電腦與手機登入同一帳號，就能使用同一份資料。登入後可以選擇將已同步書籤暫存在這個瀏覽器；正式資料仍以 Google Drive 為準。

## 第一次開啟：先做這四步

1. 用瀏覽器開啟 [書籤網站](https://melodypan.github.io/Home/bookmarks/)。
2. 點右上角「登入」，再點「連接 Google Drive」，選擇自己的 Google 帳號並允許存取。
3. 如果已經有資料，網站會載入既有書籤；若找到多份書籤集合，先選擇要使用的一份。
4. 若沒有資料，可匯入本網站的 JSON 備份，或選「建立空白書籤」。

一般使用者不需要自己建立 Google 專案。如果網站顯示尚未設定 Client ID，或 Google 說此應用程式仍在測試、你的帳號不能使用，請由網站管理者處理 [Google 設定](../apps/bookmarks/docs/google-drive-setup.md)。

連接成功後，右上角會改成「登出」，旁邊出現「設定」。書籤會放在 Google Drive 的私人 **MelodyHome** 資料夾，不必分享資料夾，也不必手動把資料檔搬進去。

## 我要找網站，應該點哪裡？

| 入口 | 看到什麼 | 適合做什麼 |
| --- | --- | --- |
| 左上角 Melody logo | 首頁及常用入口 | 回到首頁、搜尋、新增書籤 |
| 左側上方「所有書籤」 | 圖示加名稱的簡易連結，預設依網址排序 | 快速開啟網站 |
| 左側上方「常用收藏」 | 已加入收藏的簡易連結 | 開啟經常使用的網站 |
| 左側下方用途分類 | 詳細卡片與操作按鈕 | 編輯、分類、刪除、勾選或重查 |

簡易連結的名稱太長會換行，點擊會另開網站。特殊協定的網址可能無法從此網站直接開啟。

### 搜尋後可顯示詳細卡片

在「所有書籤」按「關鍵字搜尋」，輸入名稱、網址或資料夾相關文字。輸入後，結果會改成詳細卡片，提供編輯、收藏、刪除、重查及勾選功能。清空關鍵字後，回到簡易連結。

首頁也可直接輸入關鍵字搜尋。下方分類用來瀏覽特定用途；目前獨立的「關鍵字搜尋」按鈕出現在「所有書籤」，不是每個分類都有。

點「常用收藏」會清除之前的搜尋、用途、原始資料夾、狀態、重複網址及子分類篩選，顯示完整收藏清單。

### 排序與顯示方式

- 每次點「所有書籤」，預設依網址排序，收藏不會優先排在前面。
- 詳細卡片可切換「格狀／清單」及排序方式。只有格狀／清單偏好保存在目前瀏覽器，不同步到其他裝置；排序只保留在目前分頁狀態，F5 後不保留。
- 「所有書籤」使用獨立的排序設定，不會把另一個分類的「收藏優先」帶過來。
- 關鍵字搜尋通常會優先列出工作系統結果；選擇「網址排序」時，則完整依網址排序。
- 在「所有書籤」往下捲動後，右下角會出現「上」按鈕，點一下回到頁首。

管理視窗依「帳號與同步」、「本機暫存」、「資料管理」分區。授權秒數與取得時間可展開「授權詳細資訊」查看；已載入書籤後，重新匯入、匯出與備份統一放在「資料管理」。

右上角「共 N 筆」前的圓點與筆數顏色表示資料來源：藍色為 localStorage 本機暫存，紅色為直接使用 Google Drive。滑鼠停在圓點上可查看來源文字；它不表示授權或網站連線是否成功。

## 選擇本機暫存，減少重新整理等待

第一次成功登入並載入資料時，網站會詢問是否將書籤暫存在這個瀏覽器（localStorage）。同意後，F5 或下次開啟會先顯示最近成功同步的書籤，再於背景核對 Drive；內容沒變就保留原畫面，不另顯示本機暫存或背景核對的載入提示；可由藍色圓點與筆數辨識來源。不同意則維持原本的雲端載入方式。這個選擇依帳號與瀏覽器記錄，不會自動套用到另一台裝置。

修改時仍先儲存 Google Drive，成功後才替換本機快取。同步失敗時保留舊快取，未同步草稿只在目前分頁，請重試或下載備份。快取不是獨立的本機編輯模式：離線或授權到期時只能瀏覽、搜尋與開啟連結，需登入並完成版本核對後才能修改。

在右上角「設定」（未登入時按「登入」）可啟用暫存或「停用並清除暫存」。主動登出會清除書籤快取，但保留暫存選擇，下次登入可重新建立。Google 授權自然到期則保留快取供瀏覽。快取損壞或瀏覽器不允許儲存時，會回到雲端載入方式。

手機上的「所有書籤」與「常用收藏」簡易卡片固定一排兩個，長名稱可換行；關鍵字搜尋與分類的詳細卡片維持原本版面。

## 新增、修改、收藏與刪除

| 想做的事 | 操作方式 |
| --- | --- |
| 新增網站 | 回首頁，按「＋ 新增書籤」，輸入名稱、網址與分類 |
| 修改名稱或網址 | 在詳細卡片按「編輯」 |
| 加入或取消常用收藏 | 點詳細卡片上的星號 |
| 修改分類 | 點卡片下方的分類編輯按鈕 |
| 刪除 | 點卡片上的垃圾桶 |
| 復原剛刪除的項目 | 按「復原刪除」按鈕 |

修改名稱會保留原本的連線狀態。修改網址則會清除該筆舊的手動狀態與檢查結果，重新標示為「尚未檢查」。收藏與分類仍會保留。

首頁「常用收藏」提供「工作／生活」切換，沿用現有書籤用途分類（AI 工具、工作系統、程式開發與中榮資料夾屬於工作，其餘屬於生活）。切換只影響首頁收藏，不會更改全站搜尋篩選、收藏內容或排序，也不會上傳 Drive。此分頁預設顯示工作，不提供「全部」選項；沒有符合項目時會顯示提示。

首頁的「常用入口排序」可調整收藏出現的先後。使用上移／下移排序，所選用途中，全部可開啟的收藏都顯示在首頁，以緊密多欄連結清單排列，名稱前顯示網站小圖示（ChatGPT、Gemini 圖示隨網站保存，其他網站嘗試即時讀取 favicon；無法載入時不顯示圖示或備用文字）、不使用大卡片，長名稱可換行，電腦依寬度顯示 3～4 欄、平板 2 欄、手機 1 欄，依上到下排完一欄，再由左往右接續；這個順序會同步至 Drive，不等同於「所有書籤」的網址排序。

## 分類與勾選框的用途

左側「分類排序」可調整第一層分類順序。「工作系統」與「程式開發」還支援第二層分類，點主分類可展開，再點一次收合；收合不會清除右側清單。

展開後按「管理第二層分類」，可新增、改名、排序或刪除子分類。刪除子分類不會刪除書籤，而是讓相關書籤回到未分類。

詳細卡片旁的勾選框用於批次分類，以及只檢查勾選項目的網址。一般開啟網站或收藏不必勾選。「選取全部篩選結果」也包含尚未按「再看更多」展開的項目。

切回簡易連結時，勾選框與批次工具會隱藏，選取項目也會清空。部分來自「中榮」原始資料夾的書籤有工作用途限制，分類視窗會依實際選取內容提供可用選項。

## 篩選與重複網址

首頁按「更多篩選…」，可依用途、原始資料夾及網址狀態篩選。詳細清單也提供重複網址開關與目前篩選提示。

「重複網址」比對完整網址；查詢參數、片段或大小寫不同，都可能被視為不同網址。這項功能只協助找出重複，不會自動合併或刪除。卡片的「同網址 N 筆」以全部未刪除書籤計算，其他項目可能在不同分類。

按「清除所有篩選」會回到全部書籤範圍，同時清除分類、常用收藏範圍及其他篩選，不會留在原本分類。點「常用收藏」也會清除先前篩選，但顯示範圍是全部常用收藏。

## 網址檢查：線上版與本機版不同

| 環境 | 可以做什麼 |
| --- | --- |
| GitHub 線上網站 | 瀏覽、編輯、匯入、備份及同步 Drive；目前不能直接執行網址檢查 |
| 電腦本機網站 | 具備上述操作，也可執行網址檢查 |

如果線上版顯示「此網站未設定連線檢查服務」，這是目前的功能限制，不是你的 Google 登入失敗。不需要申請 Cloudflare；目前維持由本機檢查、再把結果同步到 Drive 的方式。

有需要時，由電腦在 Home 專案根目錄執行 `npm start`，開啟 `http://127.0.0.1:4179/bookmarks/`，登入同一 Google 帳號。在「設定 → 資料管理 → 網址檢查與說明」選擇全部、目前篩選、已勾選或異常／未檢查項目後執行；卡片「重查」可只檢查一筆。

**手機上的 `127.0.0.1` 是手機自己，不會連到你的電腦。** 手機平常請使用線上網址。

### 看懂檢查結果

| 狀態 | 代表什麼 |
| --- | --- |
| 可連線 | 網站回應成功，但不保證內容仍與收藏時相同 |
| 可能失效 | 回應 404 或 410，可能不存在或已移除，仍可人工確認 |
| 登入／存取限制 | 需要登入、被網站阻擋或要求稍後重試，不等於失效 |
| 待人工確認 | 逾時、網域、憑證或其他連線異常 |
| 內部／特殊網址 | 這次略過檢查，可能需要院內網路、VPN，或網址含敏感資訊 |
| 尚未檢查 | 沒有可使用的檢查紀錄 |

完成整批檢查後，結果會自動存回當日 Drive 檔案。局部重查只更新逐筆紀錄，不改變「最後完整檢查」時間。取消或關閉檢查視窗時，尚未完成的結果不套用。

手動標記的狀態優先保留。想重新使用自動判斷時，在狀態編輯中選「恢復自動檢查結果」。

## 儲存、備份與重新匯入

一般修改會自動同步，連續操作約等待 0.6 秒合併上傳。關閉或重新整理前，到「設定」確認「已同步至 Google Drive」。

| 管理視窗功能 | 用途 |
| --- | --- |
| 重新同步 | 重新讀取雲端資料；仍有草稿時先處理草稿 |
| 備份 JSON | 下載完整書籤備份，保留收藏、分類與狀態 |
| 匯出 Chrome 書籤 | 下載 HTML，供瀏覽器匯入 |
| 重新匯入 | 以本網站的 JSON 備份取代目前書籤內容，確認筆數後才寫入 |
| 下載未同步資料 | 儲存失敗時，先下載目前分頁的草稿 |

備份檔可能叫 `bookmarks-data.txt`，副檔名雖是 `.txt`，內容仍是 JSON。目前網頁匯入不直接接受 Chrome 的 HTML 匯出檔。**直接把任意 JSON 放進 Drive 資料夾，也不等於完成本網站的匯入**，請使用網站的匯入功能。

Drive 檔案為 `MelodyHome/bookmarks-YYYY-MM-DD.json`，以台灣日期每天一檔：同日更新同一檔，隔天有修改才新增。不要手動改檔案內容或刪除個別歷史版本，以免破壞版本關係。

### 同步失敗時先做什麼？

1. **先下載未同步資料**，不要直接關閉或重新整理，因為草稿只在目前分頁記憶體。
2. 確認網路，依管理視窗提示重試；授權到期時重新連接原本帳號。
3. 若兩台裝置發生衝突，先備份需要保留的內容，再選雲端版本或分頁草稿，按「使用選取版本」。網站不會自動合併兩份修改。

## 登入多久？如何登出？

Google 回傳的 `expires_in` 決定登入效期，管理視窗可查看實際秒數。曾取得的 3599 秒約為一小時，但每次以實際回傳為準。

- 不自動續期，操作也不會延長效期。
- 到期前 F5 可恢復同一分頁的登入。同意暫存時先顯示本機書籤，再背景確認 Drive；未同意時維持從 Drive 載入。
- 到期或關閉分頁後可能需要重新登入才能修改；已同意的快取仍可唯讀瀏覽。主動按「登出」會清除書籤快取與畫面。不要把快取當作未同步草稿備份。
- 右上角「登出」會中斷此網站連接，不會把整台裝置的 Google 帳號登出。

取消 Google 驗證後應可再次登入。2026-10-29 的修正也處理未收到取消通知的情況；此修正納入本輪發布，仍需實際 iPhone 驗收。詳細見 [iPhone 登入恢復說明](bookmarks-iphone-login-recovery.md)。

## iPhone 主畫面圖示與載入畫面

Safari「加入主畫面」使用網站的 Melody logo；舊捷徑可能保留原圖示，可刪除後重新加入。瀏覽器分頁則使用紫色書本圖示，兩者不同是目前設定。

F5 恢復登入時先顯示書本圖示與載入文字，避免短暫出現「0 筆／未登入」。背景更新會保留目前書籤，內容沒有變化時不重畫卡片。
